# Number Blocks Game

An interactive math game for kids featuring:
- Color-coded calculator
- Draggable number blocks
- Pattern arrangement buttons
- Real-world number examples

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

Built files will be in the `dist` directory after running `npm run build`.
These can be packaged as a PWA or converted to an APK for Android.
